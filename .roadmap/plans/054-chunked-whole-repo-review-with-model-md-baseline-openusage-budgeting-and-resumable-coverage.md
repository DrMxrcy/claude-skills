# Plan 54: Chunked whole-repo review with model.md baseline, openusage budgeting, and resumable coverage
> Type: feature · Target: v0.19.0

## 🎯 Target Scope & Boundaries
- **Core objective:** make `/adversarial-review` safe and useful on a whole codebase, including on lower-cost plans. Today a `repo` target sends one long call per member, and a rate limit mid-run loses that member's whole review. After this plan: (a) the repo is split into module chunks sized to a token budget, and each member reviews one chunk per call, writing each result as it finishes; (b) a run is resumable, and `summary.md` reports coverage per member (for example "chunks reviewed 12/40"); (c) chunks are ordered by risk (changed files, security-relevant paths first), so a cut-off run has covered what matters most; (d) a generated `model.md` in the skill's run folder records each member's baseline model and effort, the flag used to set them, the CLI version, and the date the baseline was probed, so no model or effort is guessed; (e) when `openusage` is installed, the runner reads the remaining window per member and plans how many chunk calls that member can take before its window resets, stopping it at a floor and keeping its finished chunks; (f) optional CodeGraph context: if the target repo already has a `.codegraph/` index, each chunk gets symbols and call paths from `codegraph explore` instead of raw files; the runner never runs `codegraph init` itself; (g) before any chunk is sent, secrets matched by the deny list and a secret-pattern scan are redacted from that chunk, and the chunk's file list is recorded in `summary.md` so the egress is visible.
- **Out of scope:** running `codegraph init` or any indexing; changing the single-diff and branch paths beyond sharing the chunk runner; new members; Command Code (blocked on its privacy terms); rewriting git history (handled outside this plan, before the first push to origin); automatic model selection by price or quality.

## 🏗️ Architectural Blueprint
- **Files to create:** `skills/adversarial-review/scripts/chunk_plan.py` (module chunking under a token budget, risk ordering, resume state); `skills/adversarial-review/scripts/probe_models.py` (writes `model.md`: each member's baseline model and effort flag, verified against the CLI's own `--help` output, with CLI version and probe date); `tests/test_adversarial_review_chunks.py`.
- **Files to modify:** `skills/adversarial-review/scripts/run_review.py` (run each member per chunk through the existing snapshot, guard, evidence and triage path; coverage in `summary.md`); `skills/adversarial-review/prompts/adversarial.md` (chunk-scoped instructions); `skills/adversarial-review/SKILL.md` and `README.md`.
- **Schema/interface changes:** new output files in the run folder: `model.md` (per-member baseline) and `coverage.json` (chunk id, members done, status). A `--chunk-budget <tokens>` flag and `--resume <run-dir>` flag. `model.md` is generated by `probe_models.py` and never hand-edited; the runner refuses a member whose `model.md` entry is missing.
- **Downstream impact:** the existing `diff`, `branch`, `version`, `plan` targets keep their current behaviour; only `repo` uses chunks. The privacy redaction in (g) applies to every target, so the diff path gets it too.

## ✅ Acceptance
- **Passes when:** `/adversarial-review repo` splits the repo into chunks under `--chunk-budget`, and each member gets one call per chunk, with each result written as it finishes.
- **Passes when:** after a run that stops partway (simulated by a fake member that hits a rate limit on its third chunk), `--resume <run-dir>` skips finished chunks and `summary.md` reports the coverage for each member.
- **Passes when:** `model.md` lists every included member with a baseline model, effort flag, CLI version and probe date, and a member with no entry is refused, not run with a guessed model.
- **Passes when:** with `openusage` installed and a member at a low remaining window, the runner plans fewer chunk calls for that member and records the floor it stopped at; with `openusage` missing, it plans from `--chunk-budget` alone and says so in `summary.md`.
- **Passes when:** with a `.codegraph/` index present, each chunk's context comes from `codegraph explore`; without one, the raw-file path is used and recorded; the runner never runs `codegraph init`.
- **Passes when:** a planted secret matching the deny list or the secret-pattern scan is redacted from every chunk, and `summary.md` lists the files in each chunk.
- **Passes when:** `python3.11 -m pytest tests/test_adversarial_review.py tests/test_adversarial_review_chunks.py -q -p no:cacheprovider` is green and `python3 scripts/validate_skills.py` exits 0.
- **Fails if:** a chunk is sent with a secret that the deny list or secret scan should have caught; a model or effort value is used that is not in `model.md`; a resumed run re-sends finished chunks; or `codegraph init` runs.
